# 资源自主寻找与 AI 生成

## 总原则

资源服务于锁定画面描述。先判断画面需要真实证据、真实品牌识别、公开素材还是概念示意，再选择获取方式；不要因为 AI 生成方便就替代本来应该真实呈现的对象。

按以下顺序获取：

1. 用户已经提供或项目中已经存在的素材。
2. 品牌、产品、平台或项目的官方资源与官方公开页面。
3. 来源明确、允许当前用途的公共素材库或原作者页面。
4. AI 生成的示意图片或视频。
5. 纯装饰素材；不能增加理解时直接不用。

搜索可以用于发现候选，但搜索结果缩略图不是来源。选用前必须打开原始页面，确认发布者、内容、清晰度、时效和可用方式。

## 资源类型

- `BRAND_ASSET`：Logo、图标、品牌字标和官方产品图。
- `WEB_SCREENSHOT`：GitHub、产品官网、文档、公开网页和软件界面截图。
- `PUBLIC_MEDIA`：公开图片、视频、图表或演示素材。
- `AI_IMAGE`：概念示意、风格化场景、背景、对象插图或参考锚点。
- `AI_VIDEO`：难拍场景、抽象动态、风格化短镜头、图生视频或参考引导镜头。

画面规划中的每个素材场景都要记录 `resourceMode` 和 `factuality`。`factuality` 使用 `official`、`documentary`、`illustrative` 或 `decorative`。

## Logo 与品牌资源

- 飞书、Claude、GitHub 等 Logo 优先从官方品牌中心、官方网站静态资源、官方组织页或官方媒体包获取。
- 不用 AI 生成或重绘真实 Logo；不得改变比例、品牌色、字标关系和必要留白。
- SVG 可用时优先保留矢量；ChatCut 目标路径不支持时转为足够分辨率的透明 PNG，不手工描摹。
- 官方资源无法确认时，先使用品牌名称的普通文本标签或继续寻找；不要拿搜索结果中来源不明的近似图标冒充。

## 网页和 GitHub 截图

- 需要展示真实 GitHub 仓库、README、issue、搜索结果或产品 UI 时，打开对应官方页面并截取真实当前界面，不用 AI 生成“类似 GitHub”的伪截图。
- 截图前等待页面主体、字体和图片加载完成；保留能证明上下文的页面标识，同时裁掉无关浏览器区域。
- 隐藏或裁掉账号头像、邮箱、通知、私有仓库、访问令牌、密钥、内部 URL 和其他非必要个人信息。
- 小字无法在目标画幅中阅读时，按规划使用全屏、局部放大、框选或箭头，不把整页压进小框。
- 页面内容可能变化时记录获取日期；画面依赖具体事实或版本时同时保存页面 URL 和对应文字锚点。

## 公共图片与视频

- 优先官方发布、原作者页面或条款清晰的素材库；记录发布者、原始 URL、获取日期和 `usageBasis`。
- 不直接热链搜索结果、CDN 临时签名地址或会过期的预览 URL。按 `chatcut:asset-import` 下载/导入项目，时间线引用 ChatCut `assetId`。
- 不把带水印、低清、错误比例或来源不明的资源放入成片；找不到合格素材时改用 MG、文字或 AI 示意。

## AI 图片

- 适用：抽象概念、难拍对象、风格化场景、背景、插图和多镜头一致性锚点。
- 禁用：真实 Logo、真实产品 UI、新闻现场、人物证言、产品效果证明和需要精确文字的事实截图。
- 只使用 Codex `imagegen` Skill 的内置 `image_gen`；不得调用 `chatcut:image-gen`。按锁定画幅和 Design Style 写明主体、构图、镜头、色彩、留白、用途和禁用元素；需要延续对象或风格时传入参考图，并明确每张输入图的角色。
- 不做例行确认；除非缺少必需参考图或 `imagegen` 明确要求询问，直接生成并审核。不同素材或变体分别调用一次，不用同一调用批量替代不同提示词。
- 选中的项目用图片必须从 Codex 默认生成位置复制到当前制作工作区的稳定素材目录，再按 `chatcut:asset-import` 导入；时间线只引用 ChatCut `assetId`，不能引用临时生成路径。
- 完成后检查文字乱码、手指/人脸/物体结构、Logo 幻觉、边缘、重复纹理、风格一致性和目标画幅裁切；需要透明背景时遵循 `imagegen` 的内置生成优先与本地抠图流程。

## AI 视频

- 适用：难以拍摄的短场景、抽象动态、风格化过场、图生视频、已有镜头延展或参考引导镜头。
- 禁用：伪造真实产品操作、新闻/证据画面、未经授权的真人背书，以及必须逐像素准确的界面演示。
- 严格遵守 `chatcut:video-gen`：先锁定镜头数量、时长、内容、相机和一致性锚点；一次只提交一个生成任务；用 `track_progress` 等待；多镜头复用同一对象时持续传入锚点。
- ChatCut AI 视频的付费生成、范围对齐和逐镜头结果复核属于 `chatcut:video-gen` 的必要确认，不得被“默认无人工画面审核”规则绕过；本条不适用于 Codex 内置 AI 图片生成。
- 同一身份/风格问题连续两次文字提示修正无效时，改用参考锚点或编辑模式，不提交第三次纯文字重试。
- 完成后检查主体漂移、脸/手/肢体、物体变形、镜头跳变、闪烁、文字和 Logo 幻觉、运动方向、首尾帧、时长、画幅与可用声轨。

## 来源与生成台账

每个外部寻找或 AI 生成并被采用的资源至少记录；用户原始素材和项目已有素材只需进入 S0 素材清单，不强制填写来源 URL 或生成 `jobId`：

- `resourceId`、`sceneId`、`resourceMode`、`factuality`。
- `title`、`publisherOrModel`、`sourceUrl` 或 `generationRef`；Codex AI 图片记录稳定本地路径，ChatCut AI 视频记录 `jobId`。
- `acquiredAt`、`usageBasis`、`projectAssetId`。
- `visualPlanVersion`、`activeLayoutProfile`、`cropOrPlacement`。
- AI 素材还要记录 `promptSummary`、`referenceAssetIds`、`durationOrSize` 和审核结果。

台账用于内部追溯，不在成片中机械显示来源文字。事实类画面需要在视频中署名时，按内容规范单独设计来源标注。

## 审核

S5 检查来源选择、生成路线与台账，S6 检查实际素材像素、时间和裁切，S9 检查导出画面及资源可访问性。以下任一情况硬失败：新 AI 图片没有使用 Codex `imagegen`；AI 伪造 Logo/真实 UI/事实证据；来源不明；暴露私密信息；使用临时热链；生成素材严重伪影；引用未导入项目；画面与脚本或锁定规划不符。
