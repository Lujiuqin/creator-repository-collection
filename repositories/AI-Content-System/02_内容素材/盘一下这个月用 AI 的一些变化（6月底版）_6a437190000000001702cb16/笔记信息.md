笔记标题：盘一下这个月用 AI 的一些变化（6月底版）
笔记内容：1. 先说几个常规的：
	
- 写文案用 glm5.2，AI 味去得比较好；
- 生图 chatgpt image-2，🍌pro 已经没打开过了；
- 做 PPT，定好 md 文档，codex 生图 + codia 识别，再自己微调。
  
2. 尝试用 AI 做口播视频（上一期），测了下网上风很大的 hyperframes 和 remotion。先给结论：完全自动剪辑加出 B-roll，目前不现实，除非对内容要求不高。经常会有溢出，板块表达的问题。
   
参考张咋啦老师的路径，跑通了这样一条链路：
	
- 写完并拍完剪完人像口播；
- agent 做文稿提取和时间轴对齐（可丢原稿进去比对，纠正识别误差）；
- AI 基于内容做话题拆块——判断哪段可用一幕画面讲完，生成飞书表格，供人工审板块、补图、提修改建议；
- agent 按表自动跑，逐帧抽检，设置loop 子agent 负责识别问题；
- agent自动将片段组合成完整视频。
  
最终 B-roll 基本 80 分，再人工审一遍，把不合适的画面截图回填表格定向修改，就能交付。
	
token 花得不少，但路径通了；通过 skill 把流程固化并持续调优，准确率还会往上走。
	
3. 数据分析场景（比如小红书或其他社媒），因为有墙，无论大模型还是联网搜索的 skill，都很难快速拿到准确内容——GUI 方案成本高、慢、识别准确率也低。
   
社群同学推荐个数据逆向平台，让 agent 写脚本定义抓取规范（例如：低粉高赞、一周内、行业相关爆款，要昵称、数据、评论、标题）。
	
对个人价格不便宜，但对企业一周跑一次，简直就是白给。
	
4. 这周写方案主力用 glm5.2，体验真的非常好。文字表达、上下文理解、整体靠谱程度，真实世界第一梯队。
   
长上下文理解，即使压缩后对关键细节的记忆也保留得不错；之前被诟病的速度，这一版也优化得相当可以。
	
属实把营销人和内容人的真实生产力往前推了一截。（无广，可以去问问其他人）
	
5. 前段时间想做画布形态的内容生产工具，在原来的内容飞轮上不断加功能，越做越崩；后来找到一位老师的开源产品，改一改反而能直接用了。
   
每个行业都有壁垒，工具想从零造，门槛比想象中高得多。
	
找到合适的开源项目去改，是更划算的做法。
