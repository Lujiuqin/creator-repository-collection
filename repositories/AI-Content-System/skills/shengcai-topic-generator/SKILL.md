# 航海选题助手

## 目标

读取 Vault 的项目配置、定位、有效内容素材和现有选题，生成或追加不重复、可追溯的候选选题。只规划准备讲什么，不优化标题，不写正文。

## 工作流

### 1. 定位 Vault 根目录

从当前目录向上找到项目配置文件和 `02_内容素材/`。进入 Vault 根目录后：

1. 完整读取项目配置文件；Codex 使用 `AGENTS.md`。
2. 按项目配置指定的路径读取定位文件。
3. 让项目配置中的通用规则优先于本 Skill。

### 2. 扫描素材状态

运行：

```bash
python3 <skill目录>/scripts/scan_materials.py --root <Vault根目录>
```

使用 JSON 中的以下字段：

- `valid_count`：有效内容数量。
- `valid_files`：全部有效内容文件。
- `read_files`：选题池中已记录为读取过的内容文件。
- `unread_files`：尚未处理的新内容文件。
- `existing_topics`：现有选题及其目标读者、具体问题，用于语义去重。
- `invalid_files`：无效文件及原因，仅用于说明，不把它们当作素材。

如项目配置对有效内容另有规定，按项目配置复核扫描结果。

### 3. 判断首次生成或增量生成

按以下规则选择模式：

- 选题池不存在，或选题池没有任何“已读取素材”记录：使用首次生成模式。
- 用户说“我搜集了新内容，帮我生成新选题”或同义表达：使用增量生成模式。

首次生成时：

1. 先检查 `valid_count`，不要先分析正文。
2. 少于 10 条时立即停止。
3. 告诉用户当前有效数量、距离 10 条还缺多少条，并要求回到关卡 2 补充素材。
4. 达到 10 条后，读取定位和全部 `valid_files`。

增量生成时：

1. 读取定位、完整选题池和全部 `unread_files`。
2. `unread_files` 为空时停止，说明没有尚未处理的新内容。
3. 不重新处理 `read_files`，但使用现有选题做去重判断。

### 4. 生成候选选题

遵循以下要求：

1. 让选题符合定位中当前阶段的内容优先级；定位要求首批优先 AI 科普时，先生成能够讲清楚的 AI 科普选题。
2. 首次生成 5—10 个不同选题。
3. 增量生成时，有足够不同问题就生成 5—10 个；不足时只生成能成立的数量，并说明为什么不足 5 个。
4. 每个选题只表达“准备讲什么”，不要改成夸张标题，不写正文或正文提纲。
5. 每个选题必须写明：
   - 准备写给谁
   - 解决什么具体问题
   - 主要来自哪些文件
6. 来源使用 Vault 根目录下的真实相对路径，并且只能列入本轮实际读取的文件。
7. 缺少官方定义、原始数据、本人实测或其他关键证据时，添加 `素材状态：缺素材` 并具体说明缺什么。

### 5. 语义去重

同时比较本轮候选选题与 `existing_topics`：

1. 如果目标读者、核心问题和准备讲的结论相同，只是更换工具名、模型名、数字或近义词，视为重复，只保留一个。
2. 不因标题文字不同就判断为新选题。
3. 同一主题下只有在解决的问题明显不同、能分别说明差异时才保留。
4. 宁可少生成，也不要用近义改写凑数。

### 6. 写入选题池

目标文件固定为 `04_选题库/选题池.md`。

首次生成时：

- 文件不存在则创建。
- 文件已存在则保留原文，在末尾追加一个新的候选选题区段。

增量生成时：

- 只在文件末尾追加新的候选选题区段。
- 不删除、替换、重排或改写已有选题，尤其不要覆盖用户已经确认的选题。

每个区段使用以下结构：

```markdown
## 候选选题（日期或轮次）

### 1. 准备讲的主题

- 准备写给谁：...
- 解决什么具体问题：...
- 主要来自哪些文件：
  - `02_内容素材/.../笔记信息.md`
- 素材状态：缺素材。...（仅缺素材时添加）

## 已读取素材

- `02_内容素材/.../笔记信息.md`
```

“已读取素材”只记录本轮实际读取的有效内容文件。即使新素材未形成选题，也记录已读取路径，避免下一轮重复处理。

### 7. 校验和汇报

写入后重新读取选题池并确认：

1. 新增选题数量正确。
2. 每个新增选题包含目标读者、具体问题和真实来源路径。
3. 本轮读取路径已经记录。
4. 已有内容未被删除或覆盖。

最后告诉用户：有效素材数量、本轮读取的新素材数量、新增选题数量、因重复被舍弃的方向、缺素材的选题，以及不足 5 个时的原因。

## 扫描脚本

`scripts/scan_materials.py` 只读取文件并输出 JSON，不修改 Vault。使用它完成有效素材计数、已读记录解析、新素材识别和现有选题提取。
