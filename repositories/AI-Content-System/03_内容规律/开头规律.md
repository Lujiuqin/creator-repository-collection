# 开头规律

## 候选规律

### 规律 1：【先指出现有做法不够，再提出新的判断方向】
- 大白话解释：开头先说读者正在用的办法哪里不够、哪里卡住，再把注意力转向更重要的判断，例如不要乱试工具、图片要“更好改”、稳定出图靠拆解、AI 不应只停在聊天框。
- 来源原文示例：
  - 素材 03：你想要的东西生出来了，但颜色不对、背景要换、文字要改，只能重新生成一遍，效率瓶颈卡在这里。解决这个问题的关键，不是把图生得更好看，是让图“更好改”。
  - 素材 08：“🤔 如果你还只会和AI聊天，那真的还不够！”
- 适合什么内容：AI 基础科普、工作流方法、工具能力变化、纠正常见误区的教程。
- 不适合什么内容：读者并不存在该问题、作者还没有替代方案、只能描述焦虑却无法继续解释的内容。
- 不可照搬点：不能为了制造冲突而否定读者；“不够”“瓶颈”后面必须有真实原因、方法或证据承接。

### 规律 2：【抛出选择问题，再预告解答范围】
- 大白话解释：先让读者看到自己要做的选择，再说明正文会用什么框架或哪些维度帮助判断，开头很快交代“这篇准备解决什么”。
- 来源原文示例：
  - 素材 01：“2026年AI工具真的太多了，别再一个个乱试了！我按「一人即团队」的工作流逻辑，整理了一张 2026最佳AI工具金字塔，从基础大模型到自动化工作流，基本覆盖了打工人、自媒体人、独立开发者和创业者的高频场景。”
  - 素材 04：“字节豆包专业版、腾讯 WorkBuddy、阿里 QoderWork 三家大厂扎堆出，到底选哪个？从电脑操控到价格全给你们扒明白，直接对号入座！”
- 适合什么内容：多工具选择、产品横评、分类地图、购买或订阅决策。
- 不适合什么内容：没有统一比较标准、只介绍单个工具、正文无法覆盖开头所承诺范围的内容。
- 不可照搬点：“全给你们扒明白”“基本覆盖”属于范围承诺，需要明确测评维度、使用条件和未覆盖部分。
- 来源素材：

### 规律 3：【先给可见结果，再补产品或系统身份】
- 大白话解释：第一句先把已经做成的结果摆出来，随后再解释它是什么、基于什么或处于什么发布阶段。
- 来源原文示例：
  - 素材 05：“好开心，构建好了我的 agent 员工系统<br>现在是我个人工作台，准备上线分享”
  - 素材 11：“一句话，就能交付一整套创意成品。Miora（腾讯设计妙境）是腾讯首个面向创意领域的多模态智能体工作室，基于与 WorkBuddy 同源的智能体架构打造。”
- 适合什么内容：项目展示、产品发布、工作台演示、已经跑通的实操成果。
- 不适合什么内容：结果尚未完成、只有概念图、无法展示具体产物或流程的内容。
- 不可照搬点：“构建好了”“能交付”都需要真实成果支撑；还在内测或只跑通部分流程时应说明条件。
- 来源素材：

  - 02_内容素材/腾讯首个自研创意智能体，让创作回归创意_6a603d24000000000301c82d/笔记信息.md

### 规律 4：【先交代具体机构、人物或测试，再给结果】
- 大白话解释：不先喊一个抽象观点，而是先说信息来自谁、做了什么测试或为什么值得参考，再进入分数、比较结果或作者判断。
- 来源原文示例：
  - 素材 02：“先说一下AA是谁。Artificial Analysis，不做自研、不卖API、不受厂商赞助，是目前公认独立性最强的模型评测平台。”
  - 素材 07：“DoorDash联创兼CTO Andy Fang分享说，他们内部做了个AI代码评审的测试。结果发现把Fable 5和K2.6搭配着用，不光代码质量更好，价格更低，综合效果甚至超过了sonnet加Fable 5的组合[doge]”
- 适合什么内容：模型评测解读、行业案例、成本与质量比较、有明确公开来源的变化分析。
- 不适合什么内容：来源身份不明确、测试条件缺失、只能转述二手传闻的内容。
- 不可照搬点：机构独立性、人物身份、测试条件和结果都要核验；引用来源不能替代作者自己的边界说明。
- 来源素材：
  - 02_内容素材/Kimi K3强在哪，弱在哪，一次说清_6a5f8545000000001003c435/笔记信息.md
  - 02_内容素材/半年前喊Token自由的公司，现在都不吭声了🤣_6a4f8b4e000000001c0264ff/笔记信息.md

### 规律 5：【从个人当下经历或状态进入主题】
- 大白话解释：用“我刚看到什么”“我做成了什么”“我现在是什么感受”作为入口，让后面的工具、系统或行业话题先落在一个具体经历上。
- 来源原文示例：
  - 素材 05：“好开心，构建好了我的 agent 员工系统”
  - 素材 07：“今天上午刷到个帖子有点意思[吃瓜R]”
- 适合什么内容：个人实测、项目过程、月度复盘、带有明确作者经历的工具分享。
- 不适合什么内容：作者没有参与过程的产品通稿、需要先快速交代客观结论的严肃评测。
- 不可照搬点：个人语气只能用于真实经历；不能把别人的测试改写成自己的使用体验，也不能用强情绪代替证据。

## 单条观察

### 观察 1：【直接点名特定人群并下指令】
- 观察：“设计师入门AI设计，不要只会复制提示词”先点名设计师，再用否定式指令切入，随后才给出“靠前期拆解”的判断。
- 为什么只放这里：只有 1 条开头同时出现明确职业人群、直接指令和方法转折。
- 来源原文示例：“设计师入门AI设计，不要只会复制提示词<br>AI系列海报稳定出图，不靠收集Prompt，靠前期拆解。”

## 待确认

- [ ] 汇总底稿只保留每条素材开头 1—3 句，无法判断第 4 句以后是否改变开头的完整节奏和转折。
- [ ] 素材 05 只有 2 句开头，可识别“结果先行”，但无法比较三句式开头的完整组织方式。
- [ ] 当前没有停留、读完或互动数据，无法判断哪一种开头产生了更好效果。
- [ ] “目前公认独立性最强”等来源背书属于待核验事实，正式引用前需要人工检查原始出处和时间。
- [ ] 强情绪、否定式指令和口语化表达是否符合本账号长期语气，需要结合后续实际发布结果人工确认。
