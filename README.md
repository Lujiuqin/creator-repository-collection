## 本次迁移范围

- 导入各仓库默认分支的当前文件，保留项目之间的目录边界。
- 21 个仓库含文件，2 个空仓库保留占位说明。
- 保留原有许可证、署名、可执行文件模式和符号链接。
- 登录 Cookie 排除，旧示例中的 API 凭据替换为占位符，旧插件的 Google OAuth 凭据改为读取自己的环境变量；详见 [迁移记录](MIGRATION.md)。
- 这是项目集合，网站应用仍需分别配置，技能仍需安装；迁移没有执行第三方项目代码，也没有启动任何自动发布任务。
- 本集合不会自动同步作者后续更新。具体来源提交记录在 [sources.json](sources.json)。
